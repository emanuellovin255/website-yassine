# Fontanero Yassine – Website

Web de una sola página (en español) para Yassine, fontanero en Madrid con 15 años de experiencia y servicio de urgencias 24h.

- Teléfono: **614 82 30 21**
- Formulario de urgencias que abre WhatsApp con el mensaje ya escrito
- HTML, CSS y JavaScript, sin dependencias ni paso de compilación

## Ver en local

Abre `index.html` en el navegador.
